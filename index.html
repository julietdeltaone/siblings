Getting In
PIN & Login
Enter the 4-digit PIN (hint shown on screen), then tap your name. You can only add or edit your own entries. Hit the switch icon in the top right to change users.
Profiles
Viewing a profile
Tap any sibling's card to see everything they've shared — movies, music, places, books, ideas, and upcoming availability. A green dot on the card means they've added something recently.
Editing your entries
On your own profile, each entry has a pencil (edit) and trash (delete) icon. You can only edit your own stuff.
Add Tab
Categories

Schedule Tab
Natural language

Importing a calendar file
Export your calendar as a .ics file and drag it into the import box (or tap to browse). Claude extracts all your events automatically.
iPhone: Calendar app → tap Calendars at the bottom → info icon next to a calendar → Share Link → save the .ics file → come back here and import it.
Mac: Calendar app → File → Export → Export as .ics
Undo / Redo
